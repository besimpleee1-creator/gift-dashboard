# Маленькое чудо — список подарков

React + TypeScript + Vite. Фоновая фотография владельца находится в `public/photo1.jpg`. Иллюстрации в `public/gifts/` — SVG-заглушки, не фотографии товаров.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Подключение Supabase

1. Создайте проект в Supabase.
2. Примените SQL-миграции из `supabase/migrations/` по порядку.
3. В настройках проекта скопируйте Project URL и anon/public key.
4. Создайте `.env` на основе `.env.example` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Включите Realtime для таблицы `gift_status`.
6. Запустите `npm run build` и проверьте бронирование в двух независимых браузерных сессиях.

`service_role` key нельзя помещать в `.env` с префиксом `VITE_`, клиентский код или репозиторий.

## Важно о текущем состоянии

Интерфейс и ссылки готовы. До применения SQL-миграций и настройки переменных окружения приложение работает в демо-режиме: бронирование не синхронизируется между посетителями. Не публикуйте сайт как полностью работающий список бронирований, пока не проверены миграции и права доступа.

## Публикация на Vercel

Импортируйте репозиторий в Vercel либо выполните `vercel` в папке проекта. Добавьте переменные окружения `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`, если Supabase уже настроен. Production-деплой нужно проверить отдельно.
